# 歌回索引・獨立版

這是可單獨運作的靜態網站，不依賴 ChatGPT Sites。資料取自目前線上曲庫，並加入已核對的 2023 年 6 月歌單及 7 月 4、6、8 日歌單。

- 276 場歌回、2,937 個演唱版本
- 六月新增 12 場、92 首；每首都保留起訖秒數與留言來源
- 七月目前新增 3 場、29 首；每首都保留起訖秒數與ひょうちゃん留言來源
- 支援曲名、原唱、演唱者、月份與歌回搜尋
- 同曲不同場次分開顯示；可直接查看該曲所有演唱版本
- 點曲名直接播放；播放全部與隨機播放立即開始
- 歌曲到結束時間會自動接下一首；迷你播放器有上一首、下一首與隨機播放

## 開啟

先用瀏覽器開啟 `index.html`。播放 YouTube 影片需要網路連線。若瀏覽器不允許從本機檔案載入播放器，Windows 可執行 `start-site.bat`，再開啟顯示的本機網址；這個方式需要已安裝 Python。

## 發布成公開網站

這三個檔案可直接放在靜態網站代管服務的根目錄，無須建置步驟：`index.html`、`catalog.js`、`.nojekyll`。歌單原始匯入資料另存為 `cocoa-2023-07-setlists.json`。GitHub Pages 啟用後即可使用公開網址。YouTube 影片仍由 YouTube 提供，影片可用畫質取決於原直播和連線狀況。
