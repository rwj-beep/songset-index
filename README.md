# 歌回索引・獨立版

這是可獨立使用的公開靜態網站，不依賴 ChatGPT Sites。曲庫目前收錄道明寺ここあ 2022–2023 年已匯入的歌回。

- 286 場歌回、3,015 個演唱版本
- 2023 年 6 月新增 12 場、92 首
- 2023 年 7 月共 13 場、107 首；每個版本保留開始與結束秒數及留言來源
- 同一首歌在不同場次的演唱版本分開保留
- 可依曲名、原唱、演唱者、月份和歌回搜尋；支援播放全部、隨機播放與自動接續

## 開啟

直接使用已發布的 GitHub Pages 網站。播放影片需要網路連線，畫質由 YouTube 依原始影片與連線提供。

## 發布所需檔案

將以下檔案放在靜態網站根目錄，保留檔名：

- `index.html`
- `catalog.js`
- `cocoa-2023-07-11-15.js`
- `cocoa-2023-07-19-30.js`
- `.nojekyll`

七月原始匯入資料另外保存在 `cocoa-2023-07-setlists.json` 和 `cocoa-2023-07-19-30-setlists.json`。GitHub Pages 啟用後即可透過公開網址使用。
